# Squelette de backlog par défaut (WonderWP)

Structure titre-seulement ([backlog-draft.md](../../building-backlog-plan-from-draft/references/backlog-draft.md)) utilisée par **co-constructing-backlog** pour **amorcer** le premier artefact backlog. Ne pas retirer ce bloc sans accord explicite de l’utilisateur.

```markdown
# Backlog — <projet>

## Epic: INITIALISATION PROJET
- Setup / Génération du projet
- Setup / Personnalisation de l'admin
- Setup / Configuration CI preprod
- Setup / Configuration CI prod

## Epic: HEADER
- Header / Création du template part
- Header / Intégration du header
- Header / Intégration du menu desktop
- Header / Intégration du menu mobile
- Header / Intégration du favicon

## Epic: FOOTER
- Footer / Création du template part
- Footer / Intégration du footer

## Epic: STYLEGUIDE
- Configuration des design tokens

### Epic : BLOCK LIBRARY

### Epic: HOMEPAGE

```

**HOMEPAGE** est un epic **sans puce** jusqu’à ce que l’atelier ajoute des titres d’issues.
