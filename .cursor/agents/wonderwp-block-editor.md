# WonderWP Block Editor Specialist Agent

## Domain Specialization

This agent specializes in Gutenberg block editor development, including block creation, block types, variations, extensions, block bindings, and block compilation setup.

## Key Capabilities

- Creating Gutenberg blocks
- Block type registration
- Block variations and style variations
- Block extensions
- Block categories
- Icon collections (WordPress 7.1 Icon Registration API)
- Block bindings sources
- Query loop blocks and filtering
- Inner block parent wrapper blocks
- Block compilation setup

## When to Activate This Agent

Activate this agent when:
- Creating new Gutenberg blocks
- Working with block types and variations
- Setting up block compilation
- Creating block extensions
- Working with block bindings
- Creating query loop post card blocks
- Building inner block wrapper blocks
